# Buceo Córdoba

Institutional website for the **Buceo Córdoba** diving school.

## Technical Details
- **Platform:** Angular + PHP
- **Type:** Institutional
- **URL:** [https://buceocordoba.com.ar/](https://buceocordoba.com.ar/)

## Easter Eggs
- **The Diver:** A hidden diver that, when hovered over, displays the developer's contact information.
- **The Swimming Fish:** A fish that occasionally swims across the background. The site administrator can activate a promotion so that clicking the fish grants a discount code.

> [!NOTE]
> This project is managed manually outside of the GitHub repository and is loaded via the dynamic projects configuration system.

<!-- ES -->
# Buceo Córdoba

Sitio web institucional para la escuela de buceo **Buceo Córdoba**.

## Detalles Técnicos
- **Plataforma:** Angular + PHP
- **Tipo:** Institucional
- **URL:** [https://buceocordoba.com.ar/](https://buceocordoba.com.ar/)

## Easter Eggs
- **El Buzo:** Un buzo oculto que al hacerle hover muestra el contacto del desarrollador.
- **El Pez Nadador:** Un pez que aparece eventualmente nadando por el fondo. Cuando el administrador del sitio lo desea, puede activar una promoción que al hacerle click otorga un código de descuento.

> [!NOTE]
> Este proyecto es gestionado manualmente fuera del repositorio de GitHub y se carga a través del sistema de configuración de proyectos dinámicos.
